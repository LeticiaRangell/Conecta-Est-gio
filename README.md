# 🎓 Mural de Vagas de Estágio

Projeto desenvolvido para a disciplina da faculdade com o objetivo de criar uma plataforma de divulgação e gerenciamento de vagas de estágio dentro da instituição de ensino.

---

## 📌 Descrição

O sistema permite que empresas publiquem oportunidades de estágio e que alunos possam buscar e se candidatar às vagas disponíveis.

A plataforma possui dois perfis principais:

- **Aluno**
- **Empresa**

O sistema também registra a data da candidatura realizada pelo aluno.

---

## 🚀 Funcionalidades

### 👨‍🎓 Aluno
- Visualizar vagas disponíveis
- Buscar vagas por tecnologia/tags
- Candidatar-se às vagas
- Enviar link do currículo ou LinkedIn no momento da candidatura

### 🏢 Empresa
- Publicar vagas de estágio
- Adicionar requisitos e tecnologias da vaga
- Visualizar candidatos inscritos em suas vagas

---

## 🧠 Regras de Negócio

- Um aluno pode se candidatar a várias vagas
- Uma vaga pode possuir vários candidatos
- O sistema deve armazenar:
  - Data da candidatura
  - Link do currículo/LinkedIn enviado pelo aluno
